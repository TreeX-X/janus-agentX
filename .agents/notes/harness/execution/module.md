# Task execution and handoff

## Responsibility

Run accepted scoped Tasks and preserve their fixed execution grounds.

## Design

Main Agent runtime checkpoints Progress, Evidence and Handoff before implementation and review. A selected Task retains independent review even under xdo/xdel. Runtime tools preserve leases, baseline checks and formal receipt validation; model prose is not proof of completion.
